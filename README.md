# Vault — Cassaforte privata

Applicazione web per la gestione privata dei video.

## Configurazione

Impostare in Vercel le variabili `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` usando il progetto Supabase Vault.

## Sviluppo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
